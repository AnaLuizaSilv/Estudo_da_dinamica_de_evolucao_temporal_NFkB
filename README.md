# Estudo_da_dinamica_de_evolucao_temporal_NFkB
Repositório destinado a armazenar as simulações construídas para o estágio de férias realizado em Julho de 2026 sob a orientação dos professores Juliana H. C. Smetana e Vinicius F. Wasques. O intuito do trabalho foi realizar um estudo da dinâmica de evolução temporal do Fator Nuclear kappa-B (NFkB) e espécies químicas relacionadas.
